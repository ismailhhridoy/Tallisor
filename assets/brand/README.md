# Tallisor brand assets

| File | Use |
|---|---|
| `tallisor-logo.png` | Main logo (mark + wordmark), transparent background, for light backgrounds |
| `tallisor-logo-on-dark.png` | Same logo with a white wordmark, for dark backgrounds |
| `tallisor-mark-512.png`, `-192`, `-64`, `-32` | The "T" mark alone: app icon, favicon, social avatar |
| `tallisor-logo-original.png` | The original file as supplied |

## Colours (sampled from the logo)

| Name | Hex | Where |
|---|---|---|
| Ink navy | `#031230` | Wordmark, main text, dark backgrounds |
| Deep navy | `#002284` | Start of the top bar gradient |
| Signal blue | `#0074FB` | Middle of the top bar, primary buttons and links |
| Sky cyan | `#00C1FD` | End of the top bar gradient, highlights |
| Aqua | `#00CCDD` | Lower stem |
| Mint teal | `#0CDDC8` | Lower stem highlight, positive or "matched" states |

Logo gradient: `linear-gradient(90deg, #002284, #0074FB, #00C1FD)` for the top bar and `#001C47 → #0CDDC8` for the stem.

Wordmark typeface: a geometric sans serif. A close free match for UI text is "Outfit" or "Plus Jakarta Sans" (Google Fonts).

Keep clear space around the logo of at least the height of the wordmark's "a". Do not stretch, recolour the mark, or place the navy wordmark on dark backgrounds (use the on-dark version).
